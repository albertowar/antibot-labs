# data/feeds: synthetic IP intelligence

Generated by `tools/build_world.py` from `data/world.json`; do not edit by hand. Every address is a
documentation address (RFC 5737, RFC 3849) and every ASN a documentation ASN (RFC 5398). Nothing here
describes a real network, and no lab ever downloads a real feed: the URLs below say what each file
stands in for, and how often a production stack would refresh it.

Shapes last compared with the real feeds: 2026-10. `manifest.json` holds the same table.

| File | Rows | Shaped like | Real source | Licence (real source) | Production refresh |
|---|---|---|---|---|---|
| `ip2asn.tsv` | 25 | iptoasn.com ip2asn-combined | https://iptoasn.com/ | PDDL | daily |
| `cloud_ranges.csv` | 3 | AWS, Google Cloud, DigitalOcean, Cloudflare published ranges | https://ip-ranges.amazonaws.com/ip-ranges.json (and peers) | Public | daily |
| `hosting_asns.csv` | 3 | brianhama/bad-asn-list | https://github.com/brianhama/bad-asn-list | See repository | weekly |
| `vpn_ranges.csv` | 2 | X4BNet/lists_vpn | https://github.com/X4BNet/lists_vpn | See repository | daily |
| `relay_ranges.csv` | 1 | Apple iCloud Private Relay egress ranges | https://mask-api.icloud.com/egress-ip-ranges.csv | Public | daily |
| `tor_exits.txt` | 12 | Tor Project bulk exit list | https://check.torproject.org/torbulkexitlist | Public | 30 min |
| `open_proxies.txt` | 57 | TheSpeedX/PROXY-List (discussed in W1 Ch3; never fetched by any lab) | https://github.com/TheSpeedX/PROXY-List | See repository | hourly |
| `drop_v4.json` | 1 | Spamhaus DROP | https://www.spamhaus.org/drop/drop_v4.json | Free for non-commercial use | daily |
| `firehol_level1.netset` | 3 | FireHOL level 1 (without its bogon entries) | https://iplists.firehol.org/?ipset=firehol_level1 | Per-list (see repository) | daily |

Gaps the world builds in on purpose (see `world.json`): a cloud whose ASN is on no hosting list
(`cloud_gcp`), an IPv6 cloud /64 on no list at all (`cloud_v6`), open proxies fresher than the proxy list
(`free_proxy`, 75% listed), and a privacy relay that the VPN list carries too (`private_relay`).
`firehol_level1.netset` leaves out the bogon ranges the real list includes.
